# How to Deploy

The site is static HTML/CSS/JS — no build step needed.

## GitHub Pages (Current Setup)
Already deployed at https://chauesprinciple.github.io/ChauesProductions/

To update:
```bash
git add <specific-files>
git commit -m "description"
git push origin main
```
Changes go live automatically via GitHub Pages.

## Alternative: Netlify Drop
1. Go to [app.netlify.com/drop](https://app.netlify.com/drop).
2. Drag and drop the project folder.
3. Instant live URL.

## Post-Deployment Checklist
1. **Check Links**: Click through navigation on both `index.html` and `tokyo-in-film.html`.
2. **Test Forms**: Submit a test entry on a Google Form.
3. **Verify Styles**: Confirm `index.html` uses `landing-style.css` (clean theme) and `tokyo-in-film.html` uses `style.css` (neon theme).
